# 逐页密度规划（咨询风高密度标准）

改编自 CyberPPT 密度方法论。咨询风 PPT 的密度下限远高于通用演示：
**宁可页满，不可页空**。本平台内容量目标 = 上游资产的 50%-65%（全局），
页内按以下预算执行。

## 页型 → 组件预算（2-8 个，咨询风取上限）

| 页型 | 组件预算 | 信息区构成建议 |
|---|---|---|
| `cover` | 1-2 | 主标题 + 副题（结论先行） |
| `summary` | 3-5 | 结论条 + 2-4 个关键数字 |
| `market_overview` | 4-6 | 指标卡（TAM/SAM/SOM/CAGR 各一张）+ 趋势卡/表 |
| `competitor_matrix` | 3-5 | 象限图 + 差异化机会卡 + 格局综述 |
| `user_persona` | 2-4 | 画像卡（每卡 目标/痛点/行为 三段） |
| `user_journey` | 1-3 | 时间线 + 转化点卡 |
| `feature_priority` | 2-5 | P0/P1/P2 分组表 + 摘要卡 |
| `product_architecture` | 2-4 | 分层架构卡（每层一卡） |
| `roadmap` | 1-3 | 阶段时间线（每阶段 3-5 里程碑）+ 目标条 |
| `closing` | 1-2 | 行动号召 + 关键指标 |

## 密度硬性规则

1. **指标卡即证据**：每个关键数字一张 metric 卡，且必须附带一句说明
   （数据来源或口径），禁止"裸数字"
2. **页文本总量 ≤ 2000 字、单组件文本 ≤ 360 字**（与既有规范一致）；
   单条 bullet 8-40 字、单条单结论
3. **无空白页**：生成后若某页信息区明显稀疏，必须回填
   数据细节/案例/来源说明（引用材料包证据 ID）
4. **专有名词原文引用**：功能名/竞品名/画像名/阶段名不得改写简写
5. 组件计数不含装饰性元素；每个信息区都要有证据来源

## 自检

- 每页组件数是否在预算区间内（咨询风取上限）
- 关键数字是否全部入页（材料包 key_numbers 逐项核对）
- 是否存在大面积空白（有 → 回填）

## 图表入页规则（阶段 A：数据页必有图）

- 页面含 ≥3 个可量化的同类数据（功能分级、竞品数量、趋势条数等）时，
  必须输出 1 个 chart/matrix 组件承载，禁止只用文本罗列
- 图表选型：占比→pie；趋势→line；对比/计数→bar；定位→quadrant(matrix)
- 图表数据必须来自材料包证据（真实数值/计数），禁止编造轴值
- 组件清单声明中 chart 与 card/text 并列，还原时逐项兑现（含原生图表标记）
