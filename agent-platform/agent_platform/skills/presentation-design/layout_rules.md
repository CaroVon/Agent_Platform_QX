# Layout Rules —— 布局选择指南

布局只能从以下 10 个 Layout Library 枚举中选择，选择依据是**页型与信息形态**：

| 页型 | 布局 | 使用场景 |
|------|------|----------|
| cover | cover | 标题 + 副标题 + 底部来源 |
| executive_summary | summary | 3 个以内核心结论 + 关键指标卡 |
| market_overview | market | 市场规模/趋势 + 图表或指标 |
| competitor_matrix | matrix | 竞品对比 + 象限定位 + 洞察 |
| user_persona | persona | 2-3 个画像并列卡片 |
| user_journey | journey | 步骤式旅程 + 触点 + 情绪 |
| feature_priority | features | P0/P1/P2 功能分组 |
| product_architecture | architecture | 分层架构卡片栈 |
| roadmap | roadmap | 三阶段时间线 |
| conclusion | closing | 金句 + 行动号召 |

## 叙事顺序要求

8-14 页，顺序固定：cover → executive_summary → market_overview →
competitor_matrix → user_persona → feature_priority → product_architecture →
roadmap → conclusion（user_journey 可选插入在 user_persona 之后）。
