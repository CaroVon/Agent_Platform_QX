# Information Hierarchy —— 信息层级规范

每页信息分四层，从高到低：

1. **insight（最高层）**：该页唯一结论，页面视觉焦点
2. **主视觉**：支撑结论的图表/矩阵/时间线（每页最多一个）
3. **证据**：具体数据点、案例、来源（card / table / metric）
4. **上下文**：来源与方法说明（小字，页面底部）

层级检查清单（输出前自查）：
- 若删除 insight，该页是否失去意义？→ 是，则 insight 不合格
- 主视觉是否呼应 insight？→ 否，则换组件类型
- 证据是否都来自上游资产包？→ 有编造则必须删除
