# Typography —— 排版与密度规范（完整叙事 · 高信息密度版）

- 每页标题 6-20 字，表达信息而非主题名（如"市场存在个性化缺口"优于"市场分析"）
- insight 一句话结论 10-40 字，放在页面最高层级
- bullet 每条 8-40 字、单条单结论；允许适度展开（数据/案例/来源可附）
- metric 数值必须来自上游数据，label 4-12 字；**关键指标必须附带一句说明**
  （如 "2000亿 · 2025 年市场规模（估算）"）
- table 行数上限 20 行（超出时按优先级分组分列，不删行）；**每个功能/竞品行
  必须包含描述或关键数据列**
- timeline 阶段数上限 5，每阶段里程碑上限 5 条；**每个阶段必须包含目标说明**
- 页文本总量 ≤ 2000 字；单组件文本 ≤ 360 字（高信息密度，允许排满）
- 禁止在组件 data 中放置任何字体/间距/像素参数（视觉由渲染层控制）
- **信息密度原则**：演示内容量应为上游资产的 50%-65%（宁可页满，不可稀疏）；
  页面出现大面积空白时，应补充数据细节、案例或来源说明
