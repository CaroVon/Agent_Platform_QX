# Typography —— 排版与密度规范（完整叙事版）

- 每页标题 6-20 字，表达信息而非主题名（如"市场存在个性化缺口"优于"市场分析"）
- insight 一句话结论 10-40 字，放在页面最高层级
- bullet 每条 8-30 字、单条单结论；禁止一条 bullet 写两个事实
- metric 数值必须来自上游数据，label 4-12 字
- table 行数上限 12 行（超出时按优先级分组分列，不删行）
- timeline 阶段数上限 4，每阶段里程碑上限 4 条
- 页文本总量 ≤ 600 字；单组件文本 ≤ 150 字（防止溢出）
- 禁止在组件 data 中放置任何字体/间距/像素参数（视觉由渲染层控制）
